# E-Commerce Customer Analytics and Churn Prediction

## Project Overview

This project analyzes e-commerce customer transaction data and uses machine learning to predict customers who are likely to churn.

The project focuses on understanding customer purchasing behavior, identifying important customer characteristics, and predicting customer churn based on historical transaction data.

## Objectives

- Collect and preprocess e-commerce transaction data
- Clean missing, duplicate, and invalid data
- Perform exploratory data analysis
- Analyze customer purchasing behavior
- Calculate customer-level features such as Recency, Frequency, and Monetary value
- Define customer churn based on customer inactivity
- Train machine learning models
- Evaluate model performance
- Identify customers who are likely to churn
